# Contributing to Copperline Labs projects

Thanks for your interest in contributing! How to help depends on which repository you're looking at.

## The Rendex API itself is closed-source

Rendex is a hosted API, so its core source isn't public. The best ways to contribute are:

- **Report bugs** and **request features** in the [`rendex`](https://github.com/copperline-labs/rendex) repository.
- **Improve the docs** — corrections and clarifications are welcome via issues.

## Open-source integrations welcome PRs

These repositories are open and accept contributions:

- [`rendex-mcp`](https://github.com/copperline-labs/rendex-mcp) — MCP server
- [`rendex-n8n`](https://github.com/copperline-labs/rendex-n8n) — n8n community node
- [`rendex-zapier`](https://github.com/copperline-labs/rendex-zapier) — Zapier integration

### Before you open a PR

1. **Open an issue first** for anything beyond a trivial fix, so we can align on the approach.
2. Keep changes focused — one logical change per PR.
3. Follow the existing code style and run the package's lint/type-check/tests before submitting.
4. Don't commit secrets, API keys, or `.env` files.

## Code of conduct

Be respectful and constructive. We reserve the right to remove comments or close issues/PRs that are abusive, spammy, or off-topic.

## Questions

For anything else, email [support@rendex.dev](mailto:support@rendex.dev).
